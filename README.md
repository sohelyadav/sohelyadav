### Hi, I'm Sohel 👋

I build **[Chumbaq](https://chumbaq.com)**, an open-source customer engagement platform for mobile apps:
push, in-app messages, email, SMS and WhatsApp, with audiences, journeys and A/B tests.
Self-host it or use the hosted version. Consent, erasure and export are built in.

#### Chumbaq on GitHub

| Repo | What it is | Install |
|---|---|---|
| [chumbaq-platform](https://github.com/sohelyadav/chumbaq-platform) | API, dashboard and admin app (AGPL-3.0) | self-host: see the README |
| [chumbaq-android-sdk](https://github.com/sohelyadav/chumbaq-android-sdk) | Android SDK | `implementation("com.chumbaq:chumbaq-core")` |
| [chumbaq-ios-sdk](https://github.com/sohelyadav/chumbaq-ios-sdk) | iOS SDK (Swift Package Manager) | `.package(url: "https://github.com/sohelyadav/chumbaq-ios-sdk", from: "0.1.0")` |
| [chumbaq-flutter-sdk](https://github.com/sohelyadav/chumbaq-flutter-sdk) | Flutter plugin | `flutter pub add chumbaq` |
| [chumbaq-js-sdk](https://github.com/sohelyadav/chumbaq-js-sdk) | Web SDK | `npm install @chumbaq/sdk` |

The SDKs are Apache-2.0. Issues and pull requests are welcome.
